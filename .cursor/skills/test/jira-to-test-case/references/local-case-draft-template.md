# Local case draft template (`jira-to-test-case`)

Copy this skeleton into **`.ai-sdlc/jira-to-test-case/{case_id}/docs/`** when generating a case page. File name: `{prefix}_{case_id}_v{version}_{timestamp}.md` (e.g. `TC-IOS_app-GCD-104_v1.0_20261027-180000.md` for app, `TC-CMS_app-GCD-104_v1.0_...` for cms). Bump minor version on each revision before publish; after publish, major bump on rework (same rules as `tech-solution-agent` §3.1).

**Table style**: metadata blocks use the PRD-style two-column **`Item | Content`** (or **`Field | Value`** for traceability), with a header row and `---` separator — aligned with team PRD documents.
