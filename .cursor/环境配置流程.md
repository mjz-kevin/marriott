# AI SDLC 环境配置流程

## 第 1 步：前置准备（仅 Windows）

把团队给的运行时解压包解压到 `C:\AI-SDLC\runtime\`，解压后应有两个目录：

```
C:\AI-SDLC\runtime\
├── python-3.13.x-embed-amd64\    (python.exe)
└── node-vXX.X.X-win-x64\         (node.exe / npm.cmd / npx.cmd)
```

不需管理员权限、不用改系统 PATH、不用设环境变量。

macOS / Linux 用户跳过本步，使用系统自带的 `python3` / `node`。

## 第 2 步：环境配置

在 Cursor 对话框里发一句：**配置环境**（或 **env setup**）。

助手会自动调用 `env-setup` skill，替你完成：

- 检查 `C:\AI-SDLC\runtime\` 运行时是否就位；
- 运行自检，确认能找到 `python` / `npx`（你无需手敲命令）；
- 从对应平台模板（Windows → `mcp.example.windows.json`，macOS/Linux → `mcp.example.macos.json`）生成 `.cursor\mcp.json`，并把 Windows 的 `npx.cmd` 绝对路径按自检结果自动填好。

## 第 3 步：填写凭证

打开 `.cursor\mcp.json`，自己把 3 个 token 贴到对应字段（凭证敏感，请手动填写）。

| 服务                | 填哪个字段                 | 获取地址                                                                      |
| ----------------- | --------------------- | ------------------------------------------------------------------------- |
| Confluence / Jira | `email` + `api_token` | https://id.atlassian.com/manage-profile/security/api-tokens               |
| Figma             | `FIGMA_API_KEY`       | Figma → Settings → Security → Personal access tokens                      |
| GitHub            | `GITHUB_TOKEN`        | git.marriott.com → Settings → Developer settings → Personal access tokens |

贴完后，在 Cursor 的 MCP 设置里确认三个 server（Atlassian、figma、marriott-github）都已连接，即完成。
