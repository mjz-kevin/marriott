# AI SDLC 环境配置流程

> 本文件由安装包一并放入 `~/.cursor/`。绝大多数环境准备已由安装脚本
> （`install.sh` / `install.ps1`）自动完成，你通常只需完成「第 3 步：填写凭证」。

## 第 1 步：前置准备（仅 Windows）

Windows 用户需要绿色版运行时。安装脚本会把随包的 `AI-SDLC.zip` 自动解压到 `C:\`，
解压后应有：

```
C:\AI-SDLC\runtime\
├── python-3.13.x-embed-amd64\    (python.exe)
└── node-vXX.X.X-win-x64\         (node.exe / npm.cmd / npx.cmd)
```

不需管理员权限、不用改系统 PATH、不用设环境变量。若脚本因权限无法写入 `C:\`，
手动把 `AI-SDLC.zip` 解压到 `C:\` 得到上述结构即可。

macOS / Linux 用户跳过本步，使用系统自带的 `python3` / `node`（含 `npx`）。

## 第 2 步：运行安装脚本（自动完成，无需手敲命令）

在解压后的安装包目录内运行安装脚本：

- **macOS / Linux**：`./install.sh`
- **Windows（PowerShell）**：`.\install.ps1`

脚本会替你完成：

- 把 agents / skills / profiles 与 mcp 示例复制到 `~/.cursor/`；
- （Windows）把运行时解压到 `C:\AI-SDLC\runtime\`；
- 自检 `npx`，从对应平台模板（Windows → `mcp.example.windows.json`，macOS/Linux → `mcp.example.macos.json`）
  生成 `~/.cursor/mcp.json`，Windows 会把 `npx.cmd` 绝对路径按自检结果自动填好；
- 若 `~/.cursor/mcp.json` 已存在，保留其中你已填的凭证。

## 第 3 步：填写凭证

打开 `~/.cursor/mcp.json`，自己把 3 个 token 贴到对应字段（凭证敏感，请手动填写）。

| 服务                | 填哪个字段                 | 获取地址                                                                      |
| ----------------- | --------------------- | ------------------------------------------------------------------------- |
| Confluence / Jira | `email` + `api_token` | https://id.atlassian.com/manage-profile/security/api-tokens               |
| Figma             | `FIGMA_API_KEY`       | Figma → Settings → Security → Personal access tokens                      |
| GitHub            | `GITHUB_TOKEN`        | git.marriott.com → Settings → Developer settings → Personal access tokens |

贴完后，在 Cursor 里执行 `Developer: Reload Window`，并在 MCP 设置里确认三个 server
（Atlassian、figma、marriott-github）都已连接，即完成。
